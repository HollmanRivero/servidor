1. RESUMEN DEL SISTEMA
--------------------------------------------------------------------------------
Estamos construyendo un sistema de autenticación y control de acceso para el 
Super-Server (FastAPI + Android App) con base de datos en Vercel Postgres.

Modelo comercial & control:
- Modelo: Suscripción anual de 30 € ("Peace Pass").
- Control de Paz: Poder de baneo instantáneo (Ban Hammer) con un comando SQL.
- Amigos: Capacidad de agregarlos manualmente por SQL, asignarles contraseña,
  darles 1 año de acceso (30€) o acceso VIP Gratuito de por vida.


--------------------------------------------------------------------------------
2. BASE DE DATOS (Vercel Postgres)
--------------------------------------------------------------------------------
Archivos creados en el repositorio:
- schema.sql         -> Define tablas: users, subscriptions, access_logs.
- admin_queries.sql  -> Comandos rápidos para agregar amigos, banear y consultar.

Pasos para inicializar Vercel Postgres:
1. Ir a vercel.com -> Storage -> tu base de datos Postgres -> pestaña 'SQL'.
2. Ejecutar la extensión de contraseñas:
     CREATE EXTENSION IF NOT EXISTS pgcrypto;
     CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
3. Pegar y ejecutar el contenido de 'backend/schema.sql'.
4. Copiar la variable DATABASE_URL de Vercel y guardarla en 'backend/.env':
     DATABASE_URL="postgres://default:xxx@ep-xxx.vercel-storage.com:5432/verceldb?sslmode=require"

3. COMANDOS MANUALES DE ADMINISTRADOR (Cheat-Sheet)
--------------------------------------------------------------------------------

A) Agregar un amigo (30 € / 1 Año de acceso):
   WITH new_friend AS (
       INSERT INTO users (username, password_hash, role, is_vip, friend_notes)
       VALUES ('nombre_amigo', crypt('su_password', gen_salt('bf', 10)), 'user', FALSE, 'Nota opcional')
       RETURNING id
   )
   INSERT INTO subscriptions (user_id, plan_name, price_eur, status, started_at, expires_at, notes)
   SELECT id, 'Annual Peace Pass', 30.00, 'active', NOW(), NOW() + INTERVAL '1 year', 'Pagó 30€'
   FROM new_friend;

B) Agregar un amigo VIP (Gratis de por vida):
   WITH vip AS (
       INSERT INTO users (username, password_hash, role, is_vip, friend_notes)
       VALUES ('mejor_amigo', crypt('pass_vip', gen_salt('bf', 10)), 'user', TRUE, 'Amigo VIP')
       RETURNING id
   )
   INSERT INTO subscriptions (user_id, plan_name, price_eur, status, started_at, expires_at, notes)
   SELECT id, 'VIP Friend Pass', 0.00, 'active', NOW(), NOW() + INTERVAL '100 years', 'VIP Gratis'
   FROM vip;

C) El Ban Hammer (Bloqueo instantáneo con error 403):
   UPDATE users 
   SET is_banned = TRUE, ban_reason = 'Disturbó mi paz. Que lo piense dos veces.' 
   WHERE username = 'usuario_pesado';

D) Desbanear / Perdonar:
   UPDATE users 
   SET is_banned = FALSE, ban_reason = NULL, banned_at = NULL 
   WHERE username = 'usuario_pesado';

E) Cambiar o resetear contraseña de un amigo:
   UPDATE users 
   SET password_hash = crypt('nueva_password', gen_salt('bf', 10)) 
   WHERE username = 'nombre_amigo';

F) Ver estado de todos los usuarios:
   SELECT u.username, u.friend_notes,
          CASE 
              WHEN u.is_banned THEN 'BANEADO (' || COALESCE(u.ban_reason,'') || ')'
              WHEN u.role = 'admin' THEN 'ADMIN'
              WHEN u.is_vip THEN 'VIP (Gratis)'
              WHEN s.expires_at > NOW() THEN 'ACTIVO (Vence: ' || TO_CHAR(s.expires_at, 'YYYY-MM-DD') || ')'
              ELSE 'EXPIRADO / IMPAGO'
          END AS estado
   FROM users u
   LEFT JOIN subscriptions s ON u.id = s.user_id;
